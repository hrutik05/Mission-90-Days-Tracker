# 🚀 Mission 90 Days

### Track Your Goals. Build Consistency. Measure Your Progress.

**Mission 90 Days** is a collection of personal progress-tracking files designed to help you organize your learning and preparation journey.

This repository contains two types of trackers:

- 📚 **1-Year Government Exam Tracker** — for long-term preparation for government competitive examinations.
- 💻 **3-Month Coding & Course Tracker** — for learning programming languages, completing courses, and improving technical skills.

> **Note:** This repository contains tracker files only. It is not a course, study-material repository, or teaching platform. You can use these trackers to plan your schedule, track completed tasks, and monitor your own progress.

---

## 📂 Trackers Included

### 📚 1. Government Exam Tracker — 1 Year

A structured tracker for planning and monitoring your government exam preparation over 12 months.

Suitable for preparation for exams such as:

- UPSC
- MPSC
- SSC
- Banking Exams
- Railway Exams
- State Government Exams
- Other competitive examinations

**Purpose:**
- Organize your long-term preparation.
- Track daily and monthly study progress.
- Monitor syllabus completion.
- Maintain consistency in revision and practice.
- Review your preparation milestones.

### 💻 2. Coding & Course Tracker — 3 Months

A 90-day tracker for managing programming practice, technical courses, and software development learning goals.

Suitable for topics such as:

- Java and Spring Boot
- Python
- C and C++
- JavaScript and web development
- Data Structures and Algorithms (DSA)
- Backend and full-stack development
- AI, Machine Learning, and Generative AI
- Other technical courses and learning roadmaps

**Purpose:**
- Break your learning goals into manageable tasks.
- Track course and topic completion.
- Monitor coding practice.
- Maintain a consistent learning routine.
- Measure progress throughout the 90-day period.

## 🎯 Who Is This Repository For?

This repository is for students, job seekers, and self-learners who want to:

- Prepare for government competitive examinations.
- Learn programming languages and technical skills.
- Complete online courses within a target timeline.
- Follow a structured preparation plan.
- Track personal goals and stay accountable.
